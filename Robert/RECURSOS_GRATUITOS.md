No inferir que está prohibido programar código independiente con Codex.

## Dos advertencias que importan

### Quaternius: edición y fecha exactas
[Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html) y [Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html) anuncian CC0, mientras la [licencia general](https://quaternius.com/license.html), actualizada el 28-08-2026, muestra QAL v1.0. QAL permite producto comercial y colaboración, pero prohíbe redistribución de assets sueltos. No cambia retroactivamente adquisiciones anteriores.

**No adjudicar una licencia global al catálogo.** Conservar la página, fecha, edición y LICENSE del archivo concreto. Si se conserva prueba CC0 de esa descarga, mantenerla; aclarar contradicciones antes de redistribuir. Los totales anunciados no son necesariamente el contenido del pack gratis.

### Mixamo y Sonniss: permiso comercial no es permiso para IA
- [Mixamo FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html): uso royalty-free en juegos comerciales con Adobe ID gratuito. [Términos adicionales](https://wwwimages2.adobe.com/content/dam/cc/es/legal/servicetou/Mixamo-Addl-Terms-es_ES_20210623.pdf) limitan uso de servicios/salidas para crear, entrenar, probar o mejorar IA/ML. No se verificó un clip específico de vuelo; autorig humanoide no resuelve toda anatomía.
- [Sonniss GDC](https://gdc.sonniss.com/) / [licencia](https://sonniss.com/gdc-bundle-license/): bundle gratuito con uso comercial y colaboración de proyecto; no redistribuir sonidos como assets ni usarlos para desarrollar/entrenar/mejorar IA. Catálogo 2026 declara 347+ archivos y 7,47 GB+; no descargar todo por inercia ni prometer sonidos específicos sin escucharlos.

## Qué elegir ahora
Primero una base de personaje ya autorizada, clips de movimiento imprescindibles y sonidos pequeños. Un kit urbano y un coche para la prueba. Epic o paquetes mayores solamente si la licencia, edición y adaptación están resueltas. Estos son candidatos, no dependencias aceptadas.

Antes de importar: URL + revisión/edición + fecha + licencia incluida + bytes completos + dependencia + prueba Windows + evidencia y rollback. Nada de extraer personajes Marvel/DC o archivos de juegos comerciales solo porque se puedan descargar.
